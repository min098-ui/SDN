# SDN302 - Project

Dự án bài tập môn học **SDN302**.

## 📌 Giới thiệu
Hệ thống quản lý nhóm và công việc trực tuyến (Online Team & Task Management System).

## 🚀 Công nghệ sử dụng
- **Frontend / Fullstack**: Next.js (App Router), TypeScript, Tailwind CSS
- **Database & Backend**: PostgreSQL (Supabase), Prisma ORM
- **Authentication**: NextAuth.js
- **Real-time**: Supabase Realtime

## 🛠️ Trạng thái
Dự án đang trong quá trình phát triển và hoàn thiện giao diện người dùng.
